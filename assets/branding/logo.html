SDRadio · 游戏原生风格

和 SDIMEFix、SDAtmos 同一套做法：墨迹底板、辉光标题、红印章、红飘带、UI 校准角框。标题就是电台图标本身： art/logo.svg 的「私家台」霓虹灯管，点亮成洋红色的招牌。右侧是音乐文件夹变成游戏里的电台 HUD。 HUD 上的歌名用英文：中文歌名在 HUD 上还没在游戏里验证过。

横幅

图标

「台」= 电台，取自招牌的最后一个字，灯管和游戏里的图标是同一套。缩到 32 px 时剩下口字框和上面的三角，仍然认得出。

取材

  • 标题 / 图标art/logo.svg
    电台图标「私家台」本身，同一个文件；改图标后重新渲染即可（图标的裁切范围按 neon.py 的排版算出，字距变了要更新）
  • 墨迹底板BACKING_9SLICE_LARGE / GRIT
    标题后面粗糙的黑色笔刷
  • 角框BACKING_UISCALECORNER
    画面校准时屏幕四角的 L 形辉光，保留琥珀色，和另外两个 mod 一致
  • 飘带SD_LOGO_TEXT_DE
    只借用红色斜切飘带的形式，不用官方字标和盾牌
  • 电台 HUDScreens.RadioStations
    图标 128×64、台名和歌名的位置；金属底板 BACKING_9SLICE_METAL_1 用 CSS 重画
  • 文件夹框SDIMEFix
    和 SDIMEFix 横幅里输入框同样的辉光圆角框
